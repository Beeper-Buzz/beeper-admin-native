# @instincts/spree-ui

Design tokens for Spree Admin Native and expo-spree: light and dark palettes, type scale,
spacing, radius and motion, plus `defineTheme` for brand overrides and `contrastFailures` for
WCAG AA checks. Tokens only, no React components; `@instincts/spree-ui/tokens` is the same set.

```sh
npm install @instincts/spree-ui
```

Part of [Spree Admin Native](https://github.com/1instinct/spree-admin-native). MIT.
